# Online Book Store Database Analysis (SQL)

## Project Overview
This project focuses on analyzing an **online book store database** using SQL to answer real-world business questions related to sales, customers, books, and inventory.

The goal of this project is to demonstrate strong **SQL querying skills**, logical thinking, and the ability to convert raw data into meaningful business insights.

---

## Why This Project?
I built this project to strengthen my SQL fundamentals by working on a realistic database scenario.  
It helped me practice writing optimized queries, understanding business requirements, and extracting insights that decision-makers would care about.

---

## Business Objectives
- Analyze book sales and revenue trends
- Identify top-selling books and categories
- Understand customer purchasing behavior
- Track inventory and stock availability
- Support business decision-making using SQL insights
